# 素材说明（公开仓库里有什么、没有什么）

这个仓库是 **Armed Mobs（`tarkovscav`）** 的源代码与数据包，**不包含第三方音频/贴图素材**。
本文说明**具体少了什么、为什么、以及怎么让项目重新跑起来**。

## 1. 为什么没有音频

项目里所有 `.ogg` 都来自**本地私用的第三方素材**：

| 来源 | 用途 |
| --- | --- |
| 《逃离塔科夫》游戏音效 | USEC / BEAR 阵营语音池 |
| 优质 PMC 语音包 | 优质档单位语音 |
| B 站视频切片（`BV1j1cZeHEAt`、`BV1eyZeBYEnn` 等） | 暴徒/村民/手雷喊话等片段 |

这些素材**没有公开再分发的授权**，因此本仓库**不包含任何 `.ogg`**（`.gitignore` 里的 `*.ogg` 规则）。
同样被排除的还有原始素材目录里的音频：`assets_source/voice/raw/**`、`Scav/**` 下的 `.ogg`。

**保留在仓库里的**是描述"需要哪些音频"的清单与元数据：

| 文件 | 内容 |
| --- | --- |
| `src/main/resources/assets/tarkovscav/sounds.json` | 每个 sound event 的注册与子标题 |
| `src/main/resources/assets/tarkovscav/voice_clips.txt` | 语音清单（一行一条，`#` 开头是注释） |
| `src/main/resources/assets/tarkovscav/voice_levels.json` | 逐条实测响度（dB），用于音量归一化 |
| `tools/measure_voice_levels.ps1` | 重新测量响度的脚本 |
| `tools/voice_emit.js`、`tools/voice_plan.js`、`tools/voice_inventory.js` | 语音清单的生成/盘点工具 |

## 2. 缺音频会有什么后果

* **游戏内**：语音事件不会发声（`sounds.json` 指向的文件不存在）。其余功能（AI、枪械、城区生成、维度、指挥系统等）不受影响。
* **自检（`tools/spike/selftest.ps1`）**：与音频相关的检查会**失败**，这是**预期行为**，不是代码坏了。具体是：
  * `selftest_voice.js` —— 清单里的 clip 找不到对应文件 / `sounds.json` 条目；
  * `AssetTest`（spike 编译期）—— 语音资源的完整性检查。
  
  把音频按清单放回去（`src/main/resources/assets/tarkovscav/sounds/voice/**`），这两项就会恢复绿色。

## 3. 其他被排除的内容

| 排除项 | 原因 |
| --- | --- |
| `build/`、`.gradle/`、`run/` | 构建产物与本地运行目录 |
| `libs/*.jar`、`tools/spike/citysave/jar/`、`tools/spike/citysave/backup/` | 第三方 mod jar（TaCZ）与历史构建备份，不随仓库分发 |
| `tools/spike/citysave/server/` | 一套开发用专用服务端（含 TaCZ 与存档） |
| `tools/spike/work/` 下的产物（`voice_src/`、`citycopy/`、`region_snapshot/`、`crash*/`、`*.mca`、`*.log`） | 第三方源音频、存档副本、崩溃日志等大体积中间产物；**其中的脚本（`.js`/`.ps1`/`.java`）仍会保留** |
| `mods/*.jar`、`*.zip`、`*.docx`、`*.bak-*` | 交付用 jar、历史备份与打包产物（`mods/安装说明.txt` 等文字说明保留） |
| `*.rar`、`_recon/`、`_friendfix/` | 旧的源码压缩包、反编译产物、他人仓库副本 |

## 4. 你自己跑起来需要什么

1. **JDK 17**（构建）与 **JDK 21**（跑 `tools/spike/*` 里的分析/自检工具，见 `tools/spike/selftest.ps1` 顶部）。
2. **TaCZ**（`libs/` 下的 jar 不在仓库里，需要自备；构建脚本按 `libs/*.jar` 通配找它）。
3. **GeckoLib**：构建期依赖，运行时通过 `jarJar` 内嵌，不需要另装。
4. **音频**：按第 1 节的清单自备（本地构建可直接放回原目录）。
5. 构建：`gradlew.bat build`；自检：`powershell -ExecutionPolicy Bypass -File tools\spike\selftest.ps1`。

## 5. 版权

* 代码与数据包：见仓库 `README.md` 与项目约定。
* **第三方音频/贴图不在此仓库内，也不得由此仓库再分发**；它们的所有权属于各自作者/发行方。
* 模型源素材（`assets_source/`、`Scav/` 下的 `.json`/`.png`）由项目作者提供，随仓库一并公开。
