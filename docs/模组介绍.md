# Armed Mobs（武装暴徒）· 模组介绍

> Minecraft **1.20.1 / Forge 47** · 显示名 **Armed Mobs（武装暴徒）** · 内部 mod id 仍是 `tarkovscav`
> 依赖：**TaCZ（Timeless and Classics Zero）可选**——装了就用枪，没装也能玩（单位改用弓/弩，详见 README §5ac）；
> GeckoLib 已内嵌在 `-all` 版 jar 里（普通版 jar 需要自己装 GeckoLib）。
> 本文件是**可以直接贴到模组页/帖子里的介绍**；要逐条命令与逐键配置请看
> `docs/COMMAND_AND_CONFIG_REFERENCE.md`，要看设计与踩坑记录请看 `README.md`。

## 一句话

**把"拿着枪的怪"做成会用战术的兵。** 九个武装单位会在城区里找掩体、互相压制、交替跃进、拉开距离、
撤退重组，**只在城市里生成**——不是一群直线冲锋的靶子，而是一支会跟你打阵地战的小队。
**没装 TaCZ 也能玩**：TaCZ 是可选的，没装时同一批单位改用弓或弩，上面这套战术一行都不改。

## 它到底和别的"枪械怪"模组差在哪

大部分枪械怪模组解决的是"给怪塞一把枪"。这个模组解决的是**枪手怎么用枪**：

* **掩体是一等公民**。找掩体不是"躲到方块后面"，而是搜索**可用低掩体线**（≥3 格连续、上方通透、旁边能站人），
  认领一块掩体、失守后换一块，换位期间提速、到位后压枪。
* **压制是会被执行的**。队友对着一个方向持续开火时，另一边的人真的会**趁着压制窗口前进**，
  而不是各自为战。
* **分档的智力**。`scav / sniper / troop / elite` 四档各有自己的反应时间、精度、预热、连发长度、
  暴露目标时的火力规则；同一个单位通过"精度档"随开火逐渐收敛（第一枪不准，后面越来越准）。
* **会撤退**。被打疼了会**脱离接触**、拉开距离、重新找掩体，而不是站着换血。
* **小队是一个整体**。同一支队伍共享 `squadId`、轮换掩护、交替跃进、**集火同一个目标**。
* **会走门**（开门、穿门）。**会爬梯子**（垂直寻路 + 攀爬移动 + 爬梯时不开火）。
* **会扔雷**：真实弹道求解——能算出"1 格墙能翻过去、3 格墙翻不过去"，翻不过去就不扔，
  并且会判断落点有没有队友。

## 内容清点

| 类别 | 内容 |
| --- | --- |
| **九个单位** | 暴徒 `scav`、持枪掠夺者 `gunner_pillager`、持枪村民 `gunner_villager`、狙击手 `sniper_pillager` / `sniper_villager`、四个兵种：`usec_villager`、`bear_pillager`、`elite_villager`、`elite_pillager` |
| **三个阵营** | 村民系 / 掠夺者系 / 无阵营暴徒（`scav` 两边都能出，见下） |
| **武器与配件** | 从 TaCZ 枪包里按档抽取（手枪/霰弹/步枪/狙击），随机配件、弹匣、脚本枪排除规则；**武器放置台**可以放枪让单位自己去拿（弓/弩也能拿，拿了就会射） |
| **投掷物** | 破片 / 高爆 / 烟雾 / 闪光（长引信 + 短引信），怪会自己携带、补货、在被压制时扔 |
| **护具与硬目标** | 护甲等级分档；铁傀儡一类"硬目标"会**跳弹**（枪弹伤害按标签判定） |
| **城市** | 五种城区结构：小型 `city_small`、三种变体 `city_a/b/c`、**十八栋楼的大型据点** `city_strongpoint`，外加"街区拼装器"（把街区地块拼成一大片连续城区，支持导入你自己的建筑） |
| **废土维度** | `tarkovscav:urban_wasteland`：整张地图都是城区，城市密度高、没有海、没有矿脉，靠**部署信标**进去（废土里是各方乱斗，没有占领） |
| **占领战（只主世界）** | 每座城按规模有 **20~100 的兵力池**，杀一个扣一个；**一方兵力归零就地停刷、另一方占领**；屏幕顶部有血条 HUD；`/armedmobs capture` 可查可重置 |
| **刷怪上限** | 一座城里同一阵容**最多 12 个持枪单位同时存活**（可配置），玩家手放（刷怪蛋/`/summon`）不受限——这是为了压住"城越打越多、越打越卡" |
| **一次性驻军** | 每座城第一次靠近时固定刷几队（1~5 人，可带优质队长），**永不重刷**；**阵营按楼分配**，一座城可以割据 |
| **指挥系统** | 三件阵营道具（村民/掠夺者/暴徒各一，严格只能指挥自己人）+ 信号棒 + 信号点方块；标记 A/B/C/D 中立、按维度隔离、可排队授命，单位会**走掩体推进**过去 |
| **防御道具** | **VANT 防弹盾牌**：主手或副手被动生效，正面锥形内挡枪弹（默认减免 99%），耐久 500、扣完当场碎；**手雷与爆炸默认完全不挡** |
| **语音** | 三套阵营语音池（USEC / BEAR / 优质PMC，每池 6 类）；暴徒（`scav`）按设计**不说话**（它以前借用的是掠夺者的台词） |
| **HUD 与反馈** | 击杀信息条（可配三种模式）、占领战血条、玩家歪头（lean）探身 |
| **可调性** | **344 个配置键全部有文档**，从反应时间、掩体搜索半径到"要不要让怪开门"都能改；改错了会退回出厂值并说明原因，不会静默 |
| **没装 TaCZ 也能玩** | TaCZ 是**可选依赖**：没装时模组照常加载，九个单位照样刷在城市里、照样找掩体/压制/跃进/撤退/扔雷/走门/爬梯子，只是**改用弓或弩**（`guns.fallbackWeapon` / `guns.fallbackArrows`）；只有"看枪"的报告命令会明确说一句"这个需要 TaCZ"然后返回 |

## 怎么开始（三步）

1. **装依赖（TaCZ 是可选的）**：想要枪就装 TaCZ ≥ 1.1.7 + 至少一个 TaCZ 枪包；**不装 TaCZ 也能进游戏**，这时武装单位会改用弓或弩（`guns.fallbackWeapon` / `guns.fallbackArrows`，详见 README §5ac）。GeckoLib 用 `-all` 版 jar 就已内嵌；用普通版 jar 就自己装 GeckoLib。
   ⚠️ **两个 jar 只能放一个**（同一个 modId，同时放会导致 Forge 拒绝启动）。
2. **画城市**：进世界后
   `/armedmobs city add 名字 200`（以你为中心圈一块城市区域），
   或者直接用出厂结构——`/locate structure tarkovscav:city_small`、
   或者 `/place structure tarkovscav:city_strongpoint` 手动放一座十八栋楼的大据点。
   *单位只在城市区域内生成*（`spawn.cityRegionPadding` 控制边缘容差）。
3. **开打**：站在城里等它们刷出来，或者用
   `/armedmobs spawn scav`、`/armedmobs test fight`（自动摆一场一对一的交火，
   并在日志里断言"移动了/开火了"）。
   想要废土：`/armedmobs dimension` 或用**部署信标**。

**常用命令**（全部也可以写成 `/tarkovscav ...`）：

| 想干什么 | 命令 |
| --- | --- |
| 看它现在在想什么 | `/armedmobs debug`（32 格内每只怪的完整状态机 + 阵营 + 精度 + 目标） |
| 看掩体候选点 | `/armedmobs cover` |
| 看某档能发到什么枪 | `/armedmobs gunpool rifle` |
| 指挥它们 | `/armedmobs marks`、`/armedmobs marks clear` |
| 看驻军与阵营账本 | `/armedmobs garrison`、`/armedmobs city faction` |
| 看占领战 | `/armedmobs capture`、`/armedmobs capture reset` |
| 看刷怪上限 | `/armedmobs spawncap` |
| 抽干积水 | `/armedmobs fillwater 96` |

## 性能与取舍（这部分是认真的）

* 这一版为"怪多也不卡"做过实测优化：25 只闲置单位从 **30.98 ms/tick 降到 2.16 ms**，
  50 只从 **64.00 ms 降到 3.14 ms**；交火中 8.58 → **2.54 ms**。
  尸体消失延迟从 **1.28 s 降到 63 ms**（原来要等 20 tick 才判定处理）。
* 单位死亡后会被**优先跳过**，视线判定按实体 id 错峰、精度衰减按 20 tick 节拍、
  阵营层按 4 tick、集火重试按 5 tick、寻路重发冷却 10 tick。
* 城区**刷率下调 75%**，`spawn.cityRegionPadding` 可线性压低可刷怪面积；
  城市间距在废土里是**每 384 格一座**（不会挤成一坨）。
* 所有这些都能在配置里回调——**没有一个是写死的**。

## 已知边界（诚实说明）

* **观感只能你自己看**：动作、速度、枪械挂点、血条位置、爬梯手感、HUD 可读性，
  这些没有任何自动化能替玩家判断。
* 城里**不会**出现原版怪的混战生态：这套 AI 是为"持枪单位之间打阵地战"写的。
* 攻击性很强的整合包里，**别把 `spawn.*CityOnly` 关掉**——关掉之后这些单位会在全世界自然刷新。
* 语音里的第三方音频（B站素材）**只在本机使用**，公开仓库里不含这些 `.ogg`。
* 服务端也要装（TaCZ 亦然）。客户端**不需要** TaCZ 才能启动：没装 TaCZ 时单位用弓/弩。
