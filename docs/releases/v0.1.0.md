## 这是什么

**把"拿着枪的怪"做成会用战术的兵。** 九个武装单位会在城区里找掩体、互相压制、交替跃进、拉开距离、撤退重组，
**只在城市里生成**——不是一群直线冲锋的靶子，而是一支会跟你打阵地战的小队。

和别的"枪械怪"模组差在哪：那些模组解决的是"给怪塞一把枪"，这个模组解决的是**枪手怎么用枪**：

* **掩体是一等公民**：搜索的是"可用低掩体线"（≥3 格连续、上方通透、旁边能站人），认领、失守换位、换位提速。
* **压制会被执行**：队友持续开火时，另一边真的会**趁压制窗口前进**。
* **分档智力**：`scav / sniper / troop / elite` 四档各有反应时间、精度、预热、连发长度；同一单位开火后精度逐渐收敛（第一枪偏、后面准）。
* **会撤退、会协同**：被打疼了脱离接触、重找掩体；同队共享 `squadId`、轮换掩护、交替跃进、集火同一目标。
* **会走门、会爬梯子、会扔雷**：真实弹道求解（算得出"1 格墙能翻、3 格墙翻不过去"），落点有队友就不扔。

## 装之前要知道

* **TaCZ 是可选的**：装了就用枪；**没装也能进游戏**，同一批单位改用**弓或弩**（`guns.fallbackWeapon` / `guns.fallbackArrows`）。
  战术、刷怪、城市、语音、占领战全都不变，只有"看枪"的报告命令会明确说一句"这个需要 TaCZ"然后返回。
* 本 jar **已内嵌 GeckoLib 4.8.4**，不需要另装 GeckoLib。**同一个 modId 的两个 jar 只能放一个**，同时放会导致 Forge 拒绝启动。
* **服务端也要装**（TaCZ 亦然）。
* **不含第三方音频**：语音里的 B 站素材只在本机使用，仓库和发布包都不含这些 `.ogg`。
* **344 个配置键全部有文档**：见仓库 `docs/COMMAND_AND_CONFIG_REFERENCE.md`（或同名 docx），改错了会退回出厂值并说明原因，不会静默。

## 起步（三步）

1. 把 `armedmobs-0.1.0-all.jar` 放进 `mods/`（想用枪再装 TaCZ ≥ 1.1.7 + 至少一个枪包）。
2. 进世界画一座城：`/armedmobs city add 名字 200`，或直接 `/locate structure tarkovscav:city_small`、
   `/place structure tarkovscav:city_strongpoint` 放一座十八栋楼的大据点。*单位只在城市区域内生成。*
3. `/armedmobs` 看命令树；`/armedmobs help` 里有常用项。想要 M16 还是 AK，用 `[guns]` 的枪池键挑。

## 需要你亲自验 / 已知取舍

* **观感只能你自己看**：动作、枪械挂点、血条位置、爬梯手感、HUD 可读性，自动化替不了玩家。
* **"不装 TaCZ 也能进游戏"请在真客户端确认一次**：开发环境里 TaCZ 永远在 classpath，自动化只能证明
  "没装 TaCZ 的代码路径不去碰 TaCZ 类"这种结构性事实（这一条写在 README §5ac，没有假装测过）。
* **已知取舍**：没装 TaCZ 时 `guns.fallbackArrows` 是**纯外观**——射击走原版 `ProjectileUtil.getMobArrow`
  （和骷髅同一条路），那条路不扣箭，所以实际弹药无限。要做成真消耗会和原版弓/弩自身的逻辑打架，故未做。
