Armed Mobs（武装暴徒）0.1.0  —— 测试版安装说明
================================================

【文件】
  armedmobs-0.1.0-all.jar
  sha256 = ff1973d7622b4b57036874f30de28c9f306402ec99ca99be03070f2ef405d700
  大小   = 4,476,092 字节
  （显示名是 Armed Mobs，但内部 mod id 仍是 tarkovscav —— 老存档/结构/配置照常可用；
    /armedmobs 与 /tarkovscav 是同一个指令树的两个名字。）

【运行环境（缺一不可）】
  1) Minecraft 1.20.1 + Forge 47.x（47.3.0 以上即可）
  2) TaCZ（Timeless and Classics Zero）>= 1.1.7
     *** 本模组不打包 TaCZ ***，请自行安装，并至少装一个 TaCZ 枪包；
         没有 TaCZ 时游戏会在启动阶段直接报"缺少依赖"，这是有意的。
  3) GeckoLib：已内嵌 4.8.4，无需另装；若你已经装了 4.8.2 以上也能正常共存。

【安装】
  把 jar 放进 mods/ 目录（客户端与服务端都要放）。
  服务器：TaCZ 也需要在服务端安装；首次进世界后建议执行
      /armedmobs city add 城市名 200
  来圈出"城市区域"——本模组的武装单位只会在这个区域里生成。

【本次更新（累计）】
  -14) **废土收尾：不再生成积水 + 城市间距 384 格 + `/armedmobs fillwater`**（2026-10）：
      * 成因两层：预设开着含水层（`aquifers_enabled`），城市块之间没被结构覆盖的缝隙就积了水。
        `noise_settings/urban_wasteland.json` 现在是 `aquifers_enabled: false` +
        `default_fluid: {"Name": "minecraft:air"}`（与原版末地同一套写法）→ **新生成**区块的缝隙不再有水。
      * **已经落在存档里的水**数据包改不了，所以新增 `/armedmobs fillwater [半径] [方块]`
        （半径默认 48、上限 128；方块默认 `minecraft:stone`，写 `minecraft:air` 就是抽干）：
        以执行者为中心扫一个立方体，只替换 `minecraft:water`（1.20.1 **没有**独立的 `flowing_water`
        **方块**，流动与静止是同一个带 0..15 液面属性的方块），**含水方块**（楼梯/栅栏等）只计数不替换，
        未加载的区块跳过并说明，替换位置落在扫描边界上会提示"外面的水会流回来，再来一次或放大半径"。
        日志标记 `[fillwater]`。⚠️ 只处理**已加载**区块 —— 建议一边走一边跑，或分几次跑。
      * **城市间距**：废土里 `city_variants` 5→**24**、`city_small` 4→**24** 格区块 = **384 格一座城**
        （原先 80 / 64 格一座，而预制体本身宽 48~64 格，两座城必然压边，缝隙里的水也就格外显眼）。
        `city_district`（16 格，就是那个"大城市"拼装器）与 `city_strongpoint`（192 格，据点）**故意不动**。
        只影响新生成的区块；已生成的旧城不会移动。
      * 测试用平台的边缘留白 `platform.margin` 8 → 16（只影响 RCON 搭的测试城）。
  -13) **九个武装单位会自己爬梯子**（2026-10）：
      * 原版怪物**不会**爬梯子：1.20.1 的 `WalkNodeEvaluator` 不为梯子生成垂直边，`Mob` 也没有"贴梯上行"
        的分支（只有玩家的 `LocalPlayer#aiStep` 有）。生成器造出来的梯井对怪物等于一面墙——命令点在楼上时
        它们会永远站在梯脚。现在补了三层：**垂直链接**（在半径内找合法梯井，把行程拆成
        "走到梯脚 → 爬 → 从目标层开口走出 → 继续走"）、**攀爬移动**（贴梯上下、到层才把控制权交回寻路器）、
        **爬梯意图 goal**（只在目的地确实在另一层且找到梯井时启动）。
      * 爬梯期间**不开火、不换弹**（面朝梯子，枪口在墙里），**手雷绝不在梯子上扔**；战斗与撤退**优先**于爬梯；
        被中断时落在**最近的一层**，绝不挂在半空；梯井内默认**不掉摔落伤害**（被**打出**梯井则恢复原版规则）。
      * 7 个新配置键（`[ladder]`）：`enabled`、`climbSpeed = 0.15`、`downSpeed = 0.10`、
        `searchRadius = 8`、`maxHeight = 48`、`combatWhileClimbing = false`、`fallDamageInShaft = false`。
        `enabled = false` 就回到"完全不会用梯子"的旧行为，方便 A/B。
      * **顺带修掉生成器一个真缺陷**：铺家具/掩体那一遍会占掉梯子旁边两格，导致出厂结构里
        **37 个梯井没有一个"每层都能爬"**。已加守卫（跳过每层梯子旁两格）并重新生成六个结构。
      * 没做的（诚实记录）：设计稿里"撤退时用梯子下楼"**没有**实现——撤退逻辑在 `GunAttackGoal` 里，
        实现它会违背更硬的"自保优先于爬梯"。所以撤退是**否决**爬梯。
  -12) **主世界城市争夺战：兵力池 + 血条（废土无效）**（2026-10）：
      * 用户口径："占领城市这种玩法只在主世界有"、"不被占领会一直刷几个阵容的单位，直到一方兵力消失
        （思路和战地一样）"、"废土世界完全是各种人乱斗，不需要占领"。
      * **只在主世界**：每座城按阵营建**兵力池**，大小 = `clamp(20 + 建筑数 × 2, 20, 100)`
        （同一座城里两方**开局一样多**）；该阵营每死一人扣 1；**扣到 0 该阵营在这座城永久停止刷新**，
        幸存方**占领**该城，日志写一行 `[capture] <城> captured by <胜者> (<败者> strength exhausted)`（只写一次，
        存进账本，重启也不会重复）。
      * "停止刷新"是**运行时拦截**（自然刷怪与**刷怪笼**走同一个 `MobSpawnEvent.PositionCheck`，
        驻军逐单位否决一次），**你的刷怪笼方块一个字节都不改**，随时可以 `/armedmobs capture reset` 复原。
      * **血条**：屏幕顶部居中的细条，显示每个阵营"当前/上限"，归零变灰并标"已占领"；离开城
        `hudHideDelaySeconds`（默认 8 秒）后隐藏，只剩一方时立即隐藏。纯客户端绘制、**不需要资源包**。
      * **命令**：`/armedmobs capture`（逐城列出阵营/池/是否已占领）、
        `/armedmobs capture reset [at [坐标] | <城市键>]`（按账本重建池并清掉占领标记，城重新进入争夺）、
        `/armedmobs capture set <阵营> <0..400> [坐标]`（把最近的城某阵营的池直接设成指定值，设 0 立刻判占领，
        不杀一百个怪也能测终局与血条）。
      * 8 个新配置键（`[capture]`）：`enabled`、`hudEnabled`、`poolMin = 20`、`poolMax = 100`、
        `poolPerBuilding = 2`、`drainPerKill = 1`、`playerKillsOnly = false`、`hudHideDelaySeconds = 8`。
      * **废土世界完全不变**：不建池、不判占领、永不出血条，照旧按楼分阵营乱斗。
  -12b) **顺手的两处美术清理（用户当场提的）**：

  -9) **火力纪律 + 受伤反应**（2026-09-25，`README §5ab`）：解决"面对出了掩体的敌人只会点射、打不死，
     挨打也不躲"。
     * **暴露判定**：眼睛和脚都有视线、且距离在交战范围内才算"暴露"（低墙/栅栏/单格台阶挡住其中一项就不算）。

     * **暴徒 / 狙击手保持不变**（六个键全是"哨兵"= 走原值；狙击手仍是单发守点）。

  -8) **AI 智力分档 + 小队协同**（2026-09-25，新 `[ai]` 段）：
     * **暴徒档**（武装暴徒 / 武装暴徒·掠夺者 / 武装村民）：发现你之后**愣 0.6~1.2 秒**才开枪、精度 ×0.8、
       **很少主动找掩体**、基本直线走来、不会压制。
     * **狙击手档**（狙击手掠夺者 / 狙击手村民）：**站桩守点不推进**、只挑**有遮挡/略高**的射击位、
       命中把握不够就**不开枪**（门槛 0.5，约 48 格外才拒射；最迟 3 个窗口必开一枪防自锁）、被接近或挨打会换点。
     * **部队档**（USEC村民 / BEAR掠夺者）：反应快、**中距离掩体推进**（小步、少暴露）、**压制更久更密**、参与协同。
     * **优质档**（优质村民 / 优质掠夺者）：反应最快、**贴到约 60% 射程**才开火、长步/短冲刺推进、参与协同。
     * **协同四件**（部队 + 优质）：集火同一目标 / 交替掩护推进（角色轮换）/ 两侧包抄 / 掩体不重叠（占位有主、到期释放）。
     * 配置：`[ai] enabled`（总开关，false = 回到只有全局 `[tactics]` 的旧行为）、`[ai.scav|sniper|troop|elite]`
       四档各自的旋钮（都是**乘在**原全局键上的系数，你调过的 `[tactics]` 数值仍然有效）、`[ai.coordination]` 十二个键。
       README §5aa 里有**"把四档都调回暴徒水平"**的配方（想安静点就照它填）。改完 `/armedmobs client reload` 即生效。
       （新键会由 Forge 自动补进你现有的 toml，不需要删配置。）
  -7) 所有武装单位**会开门、也会关门**（2026-09-25）：新增 `gun/DoorBehavior`，九个单位（暴徒/掠夺者/村民/
     狙击手/部队/优质）在交战状态下都会推开木门通过，并在通过后**把门关上**（播放原版关门声）。
     安全规则：门洞里站着任何活体（包括它自己）就绝不关；铁门/金门这类打不开的门一律不碰；
     单位还顶着门时只重置计时器，从构造上杜绝"开关开关"循环。
     新 `[ai]` 段三个键：`closeDoorsBehind`(true) / `doorCloseDelayTicks`(40) / `doorCloseAllyRadius`(2.0)。
     （顺带修正一个此前的误解：`GunUser#allowDoors()` 只是**放宽寻路器**，原版里真正推门的是 Goal，
     而只有 Vindicator 注册了它 —— 所以在这次改动之前，九个单位**交战中都开不了门**，不只是不会关。）
  -6) 手雷不再被掩体吃掉（2026-09-25）：以前是**直线投掷**（`direction = 目标 - 自己`，没有仰角），
     15~20 格外中间一堵矮墙/围栏就把它截住。现在按 vanilla 的真实物理（重力 0.03/tick、阻力 0.99）
     逐步模拟弹道，扫若干仰角取"落点最接近目标**且途中不撞方块**"的那条弧；并且
     **"预测落点"与"实际投掷"共用同一个求解器**（原先是两份各算各的）。
     对着满高墙**不扔、不消耗手雷**（日志：`held the throw: arc blocked by cover at (x,y,z)`），
     对着矮墙会吊射过去（1 格墙实测余量 0.17 格；2~3 格墙判为不可扔）。
     新增 4 个键：`mobGrenadeArcSamples`(13) / `mobGrenadeRequireClearArc`(true) /
     `mobGrenadeMaxLaunchPitchDegrees`(45) / `mobGrenadeRetryCooldownTicks`(40)。
     注意：投掷散布改成 0（否则"预测的弧"和"实际扔的弧"又会分叉），近距离（6~9 格）默认不再扔雷。

  * 9 种武装单位：武装暴徒（Scav）、武装暴徒·掠夺者、武装村民、狙击手掠夺者、狙击手村民、

    创造模式另有"创造武器放置台"（创造物品栏，无配方），枪是模板、永不消耗，
    可以无限把村民/掠夺者变成持枪单位。

    区域内），但城市地面多为建筑与照明，原版刷怪位置判定很难通过，实测日志里自然生成
    0 次成功、刷怪笼刷出的全部通过。需要人口时用刷怪笼或 /armedmobs spawn。
